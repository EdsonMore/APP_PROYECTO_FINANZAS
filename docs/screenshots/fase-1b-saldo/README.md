# Capturas: saldo inicial (fase-1b)

Emulador Android API 37, 1080×2400, app real. Modo Variable con un gasto de
S/ 12 registrado hoy antes de fijar el saldo.

- `saldo-boton-deshabilitado.png`: monto vacío, "Guardar saldo" deshabilitado.
- `saldo-cero-ok.png`: S/ 0 tecleado; el botón se habilita (S/ 0 es válido).
- `saldo-hoja-claro.png` / `saldo-hoja-oscuro.png`: S/ 1,100 tecleado.
- `home-con-tarjeta-claro.png` → `home-sin-tarjeta-claro.png`: antes y después
  de guardar S/ 1,100. "Sin colchón" pasa a "~91 días": el gasto de S/ 12 se
  registró antes de fijar el saldo, así que ya está incluido en los S/ 1,100.
