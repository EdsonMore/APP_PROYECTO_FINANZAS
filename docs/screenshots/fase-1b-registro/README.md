# Capturas: registro de gasto e ingreso (fase-1b)

Emulador Android API 37. El Home todavía no existe: las hojas se abrieron
desde un punto de entrada temporal que no está en el repo.

- `registro-gasto-nota-claro.png`: el teclado completo del sistema (Gboard con
  "Show on-screen keyboard" activado y la escritura con lápiz desactivada). El
  campo de nota se ve entero, "Guardar" queda encima del teclado y el teclado
  propio está oculto.
- `registro-gasto-compacta-claro.png`: 720×1280 a 320 dpi (≈ 360×640 dp),
  simulado con `wm size` y `wm density`. Los chips llevan íconos y "Agregar
  nota" es el último chip.
- `registro-gasto-guardando-claro.png`: el insert se retrasó 4 s a propósito
  para poder capturar el spinner. El guardado real tarda milisegundos.
