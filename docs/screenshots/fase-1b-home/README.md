# Capturas: Home (fase-1b)

Emulador Android API 37, 1080×2400 a 420 dpi, con la app real (`HomeScreen`).
Los datos de ejemplo se cargaron desde un punto de entrada temporal que no está
en el repo, porque en la 1b todavía no se pueden crear presupuestos desde la UI.

- `home-estable-con-techos-claro.png`: techos de S/ 2,000 en total, ingreso
  registrado en el mes.
- `home-supervivencia-*.png`: S/ 1,500 de saldo inicial cargado hace 20 días,
  una venta de S/ 120 y gastos diarios. Semáforo en rojo, runway positivo.
- `home-deshacer-claro.png`: un gasto de S/ 12 registrado desde "− Gasto" en el
  estado Variable; el aviso flota encima de los botones.
